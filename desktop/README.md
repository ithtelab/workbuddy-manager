# WorkBuddy Manager 桌面版（可选）

一个很小的原生窗口程序，把现有的管理面板装进窗口里：双击即启动本机服务，面板直接
出现；托盘里有服务状态、更新检查和用量概览；发现新版本可以一键更新并自动重启。

本目录是**独立的外壳与安装包**，不修改 `server/`、`web/out/` 的任何代码，也不改动
原有的启动脚本；不用它时，项目照旧可以用脚本或容器方式运行。

## 目录

| 路径 | 用途 |
|---|---|
| `src/` | .NET 8 + WebView2 外壳（窗口、托盘、服务启停、自动登录、更新器） |
| `src/WebAssets/` | 启动页、更新页、错误页、托盘弹窗（HTML，内嵌进 exe） |
| `setup/src/` | 安装程序：选择目录、解压运行时、写配置、建快捷方式、注册卸载项 |
| `setup/uninstall/src/` | 卸载程序：只删除本程序的目录 / 快捷方式 / 注册表项 |
| `build.ps1` | 构建外壳，产物在 `app/`，单文件时复制到项目根目录 |
| `setup/build-setup.ps1` | 构建单文件安装包 `setup/dist/WorkBuddyManagerSetup.exe` |

## 使用

```powershell
# 构建外壳（产物在 desktop\app\，单文件时复制到项目根目录）
powershell -ExecutionPolicy Bypass -File desktop\build.ps1

# 构建安装包（内嵌 Python 运行时、上游网关与前端产物）
powershell -ExecutionPolicy Bypass -File desktop\setup\build-setup.ps1
```

- 双击项目根目录的 `WorkBuddyManager.exe`：启动上游网关与管理服务，窗口里显示面板；
- 关闭窗口 = 最小化到托盘，服务继续运行；
- 托盘弹窗：「配置」页显示服务状态、版本、上游连接，以及打开主窗口 / 检查更新 /
  重启服务 / 打开安装目录 / 自动登录 / 开机自启 / 退出；「用量」页显示当日、近 7 天、
  近 30 天与全部的请求数、Tokens、消耗积分、缓存命中率与成本趋势；
- 窗口默认最大化；托盘弹窗按内容自适应高度。

## 一键更新

- 启动时与每 6 小时静默检查一次，不在启动时弹窗；
- 发现新版本时，面板右下角出现更新提示，点「立即更新」直接在页面里显示进度并完成，
  结束后自动重启服务、刷新面板；
- 也可以从托盘「检查更新」打开独立窗口（`--show-update` 启动参数同样可以）；
- 更新只替换 `server/`、`web/out/` 等程序文件，`.env`、`data/`、`upstream/`（账号与
  配置）和 `desktop/` 不会被替换；
- 替换前备份旧目录，新版本启动失败可一键回滚；面板与更新窗口共享同一个更新锁，
  同时只会有一个更新任务。

## 自动登录

- 安装程序可在本机写入初始账号（默认 `admin` / `admin123`），首次启动自动登录；
- 手动登录成功后，外壳会记住账号密码（Windows DPAPI 加密，保存在本机设置目录），
  下次启动直接登录，不需要再输入；
- 关闭「自动登录」开关后不再保存与自动登录。

> 面板自身有密码策略，`admin123` 属于弱口令。默认账号只适合本机自用；如果要把
> 面板开放到公网，请先在「设置 → 管理用户」里改成强密码。

## 安装与卸载

安装包是单个 exe（内嵌 Python 运行时、上游网关、前端产物），目标机只需 Windows 10/11、
WebView2 运行时和 .NET 8 Desktop Runtime：

- 安装时可以选择安装位置；
- 会创建桌面与开始菜单快捷方式，并注册到「设置 → 应用」；
- 安装目录里的 `Uninstall.exe` 用于卸载：只停止本程序的服务、删除**本程序的安装目录、
  快捷方式和注册表项**，其他文件不动；可勾选「保留账号与配置数据」，会先把 `data/`
  备份到 `%LOCALAPPDATA%\WorkBuddyManager\uninstalled-data-<时间>` 再删除目录；
- 卸载前会校验目标目录确实是本程序的安装目录，路径异常直接拒绝。

## 其他说明

- **改名/移动目录**：整个文件夹可以移动或改名，启动时会把 `.env` 里指向旧目录的
  路径自动校正到当前位置；
- **外部实例保护**：如果端口上的服务来自另一个目录，外壳以「外部实例（只读）」打开，
  可浏览与检查更新，但禁用停止/重启/安装更新，避免误杀正在使用的服务；
- 外壳自身不做远程自更新；更新的是项目代码，需要更新外壳时替换 exe 即可；
- 原生模式的上游 `wb2api.exe` 不在发布包内，更新上游仍按原方式重新编译。
